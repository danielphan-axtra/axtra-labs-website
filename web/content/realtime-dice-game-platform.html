Real-Time Dice Game Platform

Real-time multiplayer dice game with provably fair draws and an in-game wallet. Team of 9 over 10 months.

Multi-Game iGaming PlatformCrypto iGaming Platform

Key Details

ChallengeAn emerging online gaming operator in Asia needed a real-time multiplayer over-and-under dice game with fair draws, a wallet and payment gateways.
SolutionA Node.js game server with live multiplayer updates, a React client, provably fair hashing, and an in-game wallet on auto-scaling cloud infrastructure.
TechnologiesNode.js, Express, Socket.IO, React, Tailwind, PostgreSQL, Redis, JWT, AWS ECS, CloudFront, S3, RDS, Datadog, CloudWatch, GitLab CI
