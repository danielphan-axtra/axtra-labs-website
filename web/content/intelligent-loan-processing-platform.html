Intelligent Loan Processing Platform

Key Details

ChallengeA US fintech lender funding SMB loans and equipment purchases needed to take in and check large volumes of loan documents.
SolutionAn ASP.NET and React platform with Azure ingestion, Form Recognizer extraction, a validation engine and bureau and banking integrations.
TechnologiesASP.NET Core, React, Azure Functions, Azure Blob, Azure AD B2C, Azure DevOps, Azure Form Recognizer

Technologies used

Client

The client is a fast-growing US fintech lender working on SMB loans and equipment financing. The platform takes documents in, extracts fields and validates them against connected data sources.

What we built

  • ASP.NET and React platform
  • Asynchronous document ingestion on Azure
  • OCR extraction with Azure Form Recognizer
  • Validation engine
  • Integrations with Plaid, Equifax and Experian

Engagement

Delivery was time and materials with 8 engineers. The initial term was 3 months. It was extended 7 times and ran for 23 months.
