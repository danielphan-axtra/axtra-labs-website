Client

The client is a US-based robotics company building home robots for everyday physical tasks. The platform combines custom hardware, embedded software, perception, controls, autonomy and machine learning so a robot can work around people and pets. The reference names laundry and room reset as example tasks.

What we built

  • Embedded software, firmware and device drivers
  • Robot control, autonomy, middleware and system integration
  • 3D perception, visual SLAM, sensor fusion and localization
  • Computer vision, robot learning and model training
  • Data pipelines, dataset processing and model evaluation
  • Hardware and software integration, simulation, diagnostics and automated testing
