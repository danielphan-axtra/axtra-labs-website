Multi-Game iGaming Platform

Sports, slots and cultural games on web and mobile for an online gaming operator in Asia. Team of 13 over 12 months.

Crypto iGaming PlatformWeb3 SportFi Platform

Key Details

ChallengeA fast-growing online gaming operator in Asia needed one platform for sports, slots and cultural games, on web and mobile, with compliance, payments, a wallet and third-party providers.
SolutionA modular web and mobile platform with a custom real-time wallet, multi-language and multi-currency support, identity checks, and cloud monitoring.
TechnologiesASP.NET Core, Entity Framework, React, TypeScript, Tailwind, Azure Functions, Azure Blob, Azure Computer Vision, Azure Form Recognizer, Azure AD B2C, Azure Monitor, Application Insights, Azure DevOps, Jira, Confluence

Product screenshots

What we built

  • Modular architecture for sports, slots and cultural games, including Lô Đề, Xóc Đĩa and Bầu Cua
  • Web and mobile clients
  • Custom wallet with real-time balances
  • Multi-language and multi-currency support
  • Payments and third-party provider integration
  • Identity checks using computer vision and document recognition
  • Cloud hosting with CI/CD, directory sign-in, monitoring and ongoing QA and maintenance
  • 24/7 monitoring

Engagement

Delivery was an offshore development center engagement with 13 engineers over 12 months, with ongoing QA and maintenance.

Project team: 13 engineers. Duration: 12 months. Model: OSDC.

Outcome

The platform covers the game catalog, wallet, payments and monitoring described above. No separate performance figure is stated.
